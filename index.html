CLI Documentation

Standard syntax for ./client

Client Manager Login (Controller) MANAGER 
# Used to log in to the management interface and control installed clients
./client -u <user> <password>
Standard Client Installation CLIENT 
# Install the client so this server can be controlled by the Manager
# --name: Set an identifier for this server on the system
./client -c <user> <password> --name "Server-Prod-01"
Persistent Connection (Persist) CLIENT 
# Keep the connection alive, auto-reconnect on network drops. Does NOT auto-start on reboot.
./client -c <user> <password> --name "Server-Dev" --persist
Run as System Service (Recommended) SYSTEM SERVICE 
# Turn the host into a system service.
# Includes --persist functionality + Auto-restarts on system reboot.
./client -c <user> <password> --name "Server-DB" -r
Uninstall CLIENT 
# Completely remove the previously installed client and service from the machine
./client --uninstall
WebSocket & Future Roadmap NETWORKING 
# Specify WSS connection (defaults to anontokenforever.dpdns.org)
./client --ws wss://anontokenforever.dpdns.org -u ...

# [FUTURE] Direct connection via traditional IP and Port
# ./client -s <host-ip> -p <port> ... (In development)

🖥️ Manager Interactive Shell

After logging in as Client Manager, you enter an interactive shell to manage your connected devices.

Example Session INTERACTIVE 
$ ./client --ws wss://anontokenforever.dpdns.org/tedex -u user password
manager user — type help

user@tedex> list
Connected devices:
  1. Server-Prod-01 (online)
  2. Server-DB (online)
  3. Server-Dev (offline)

user@tedex> attach Server-Prod-01
[Attached to Server-Prod-01]
Now controlling the remote shell. Type 'exit' to disconnect.

user@Server-Prod-01:~$ ls -la
total 24
drwxr-xr-x 3 user user 4096 Oct  2 10:15 .
drwxr-xr-x 5 root root 4096 Sep 28 09:00 ..
-rw-r--r-- 1 user user  220 Sep 28 09:00 .bash_logout

user@Server-Prod-01:~$ exit
[Disconnected from Server-Prod-01]

user@tedex> remove Server-Dev
[Removed Server-Dev - client stopped and uninstalled]

user@tedex> exit
Goodbye!

list

Shows all connected devices with their status (online/offline) and device IDs.

attach <device_id>

Connect to a client's shell for remote control. Type exit while attached to disconnect and return to manager prompt.

remove <device_id>

Stop the client service and completely uninstall it from the target server.

exit

Exit the Manager shell and close the connection to the Tedex server.

💡 Pro Tip: When you're attached to a client shell and type exit, you'll be returned to the Manager prompt (user@tedex>). To fully exit the Manager shell, type exit again.
